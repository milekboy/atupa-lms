## Running locally

From the project root, run `npm run test:admin-release`. Use an installed Playwright module (`playwright` resolves normally, or set `PLAYWRIGHT_MODULE` to its module path) and installed Chrome (`PLAYWRIGHT_CHROME_EXECUTABLE` may provide its path; otherwise the Chrome channel is used). No browser package is installed automatically. Missing browser tooling leaves local acceptance incomplete. `--skip-browser` explicitly records not-run and exits incomplete; it cannot produce a green acceptance report. `--webpack` supports an isolated staging copy whose node_modules is a symlink; the normal real-project run uses the ordinary build.

For focused runs: `npm run test:admin-foundation -- --regression --report /tmp/admin-http.json`, `npm run test:admin-foundation -- --trust --private-attachments`, and `npm run test:admin-browser`. The runner supplies synthetic API/session/origin values to child processes only. It does not alter `.env` files or enable private screenshots/checkout on the real app. Do not substitute real credentials into mocks.
