## Step 1 fixture coverage

- Four console roles: Super Admin, Support Admin, Content Creator and School Admin.
- Denied roles: learner, parent and teacher; public registration cannot create Support Admin.
- Support variants: empty permissions, denied response, 503, malformed contract and expired session.
- Adversarial menus: foreign URL, unknown/future destination, duplicate key and key/path mismatch; permissions role mismatch fails closed.
- Existing six-role shell, legacy admin lifecycle, and all existing HTTP fixture groups are regressed locally. School fixture denial remains synthetic; a real two-school test is still required.
